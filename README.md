# Stereo Mind: Cognitive OS

> **Build your mind like a system.**

Stereo Mind is an ambitious, open-source knowledge architecture. It's not just an app; it's a personal infrastructure designed for tracking learning, visualizing cognition, and engineering a systematic life.

![Stereo Mind Banner](public/logo.png) <!-- Note: Add your logo/banner here if you have one -->

## 🌐 Overview

Traditional productivity tools treat the brain like a passive container for tasks. Stereo Mind treats it like a high-fidelity processor, providing a unified cognitive infrastructure to track learning, visualize cognition, and engineer intentional growth.

**v0.1.0-alpha // Open Source Protocol // Stable Branch: Main**

## 🚀 Key Features

- **Neuro-Logging**: High-granularity session tracking with technical metadata.
- **Knowledge Graphs**: Visual links between disparate topics using WebGL/3D renders.
- **Analytic Engine**: Deep insights into cognitive peaks and learning plateaus.
- **Skill Engineering**: Treat skills like software dependencies. Track mastery and versioning.
- **Data Sovereignty**: Your data belongs to you. Export to JSON/CSV or host locally.
- **Gamification (Roadmap)**: XP, levels, and streaks for consistent engagement.

## 🛠 Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Database & Auth**: [Supabase](https://supabase.com/)
- **UI Components**: [Radix UI](https://www.radix-ui.com/), [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Package Manager**: [Bun](https://bun.sh/)

## ⚙️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/xCyberpunkx/stero-mind.git
cd stero-mind
```

### 2. Install dependencies
```bash
bun install
```

### 3. Environment Configuration
Create a `.env` file in the root directory and add your Supabase credentials:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_DEFAULT_KEY=your_supabase_anon_key
```

### 4. Run the development server
```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to view the protocol.
